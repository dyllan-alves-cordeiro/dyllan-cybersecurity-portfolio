## Condições obrigatórias

- [ ] Dyllan aprovou o nome profissional e o posicionamento.
- [ ] Dyllan aprovou o conteúdo factual exposto.
- [ ] Contatos, LinkedIn, GitHub e demais links foram fornecidos e revisados.
- [ ] Currículo-base, formação e certificações foram validados.
- [ ] Três a cinco cases publicáveis foram aprovados.
- [ ] Idioma inicial definido.
- [ ] Domínio-alvo definido.
- [ ] Estratégia de hospedagem definida.
- [ ] Build final e checagem visual desktop/mobile aprovados.

## Regra de honestidade

Build verde, screenshot ou URL local não significam publicação. O handoff só poderá dizer
`PUBLISHED` quando existir evidência do ambiente público e do domínio definido.
